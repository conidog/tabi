# Aloha Planner（公開版）

ハワイ旅行のスポットを選んで、1日ごとの予定としおりを作るページです。

- スポットのデータ（NotionのHAWAII TRIPから書き出したもの）は `index.html` の中に入っています。
- 作ったプランは、使う人それぞれのブラウザに保存されます。Notionには書き込みません。
- スポットの「Notion ↗」から、公開しているNotionのページが開けます。

## GitHubに置くもの

- `index.html`
- `img` フォルダ（トップの写真。なくても動きますが、写真が出ません）

リポジトリの「Add file → Upload files」に、この2つをまとめてドラッグすればOKです。

## スポットを更新する

Notionのスポットが変わったら、新しい `index.html` を作って差し替えます。
